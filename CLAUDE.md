# CLAUDE.md — «Электросмета»

Калькулятор для подработки пользователя: электромонтаж в новых каркасных домах. Штроб нет, кабель заводится до обшивки ГКЛ. Язык общения: русский, вопросы задавать по одному.

## Приложение
- PWA: index.html + manifest.webmanifest + sw.js (офлайн) + icon-180/192/512.png. Без внешних зависимостей. На iPhone ставится через Safari → «На экран Домой».
- Данные в localStorage, ключ `elek_v1`. На том же домене github.io живут трекер (`life_v1`, кэши `kurs-`) и английский (`eng_v1`, кэши `eng-`), поэтому sw.js удаляет только свои кэши `elek-`.
- Вкладки: Смета (количество работ по объекту, кнопка «Рассчитать смету», скидка, отправка текстом), Материалы (количество и список «К покупке» с отметками, без цен), Расходники (свой список с ценами, количество по объекту, переключатель «добавлять в смету»), Настройки (цены на работы, список работ и материалов, резервная копия текстом, тема).
- Формат данных v2. Новые пункты каталога получают явные id (см. `V2` в index.html) и добавляются в `migrate`, чтобы у тех, кто уже пользуется, не сдвинулись старые id.
- Работы и материалы общие для всех объектов. У объекта свои количества и разовые позиции (разовая работа, «свой вариант» материала).
- Смета считается по текущим ценам: смена цены пересчитывает все объекты.
- Дизайн свой (графит + электрический жёлтый, сетка-«чертёж», моноширинные цифры). С трекером и английским не смешивать.
- Локальная проверка: конфигурация `electric` в `../трекер привычек/.claude/launch.json` (порт 8767).

## Правила
- Цены и пункты задаёт сам пользователь, свои расценки не подставлять.
- Новые функции добавлять только по запросу, интерфейс не раздувать.
